# Handle

A small, responsive GitHub username availability checker built with React and Vite.

## What it does

- Checks usernames against the public GitHub Users API.
- Distinguishes available, taken, invalid, rate-limited, and offline states.
- Links directly to an existing GitHub profile when a handle is taken.
- Validates GitHub's username rules before making a request.

## Run locally

```bash
npm install
npm run dev
```

Use `npm run build` to create a production build and `npm run lint` to check the source.
